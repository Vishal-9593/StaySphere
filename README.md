# 🏡 StaySphere

A full-stack **Airbnb-inspired property listing platform** where users can explore, create, update, and review beautiful places to stay. StaySphere provides a complete travel accommodation experience with authentication, image uploads, location mapping, and review management.


## 🚀 Live Demo
🔗 https://wanderlust-bj4t.onrender.com

## 📌 Features

### 👤 User Authentication
- User registration and login
- Secure authentication using Passport.js
- Session-based user management
- Authorization for listing owners

### 🏠 Property Listings
- Create new property listings
- Edit and delete your own listings
- View detailed property information
- Upload property images
- Category-based property filtering

### ⭐ Reviews & Ratings
- Users can add reviews
- Delete their own reviews
- Rating system for properties

### 🗺️ Location Features
- Interactive maps using Mapbox
- Location-based property visualization
- Geocoding support for listings

### ☁️ Image Management
- Image upload using Multer
- Cloud image storage using Cloudinary
- Optimized image handling

### 📱 Responsive Design
- Mobile-friendly interface
- Clean and modern UI
- Bootstrap-based responsive layouts
