# StaySphere 🏠

A full-stack Airbnb-inspired property listing platform.

## Features
- User authentication
- Create, edit, delete listings
- Image upload using Cloudinary
- Location maps
- Reviews and ratings
- Category-based filtering

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Bootstrap
- Cloudinary
- Mapbox
